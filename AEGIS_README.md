# Aegis Companion 0.6.0 — Command Center

Branch de desenvolvimento do mod Fabric 1.20.1.

Esta versão adiciona painel gráfico, patrulha, posturas de combate, filtros de coleta, depósito automático, reabastecimento do dono, autoequipamento e retirada de emergência.

O workflow compila, valida os recursos, verifica as classes críticas do JAR e publica o mod, sources JAR e projeto-fonte como artefato.
